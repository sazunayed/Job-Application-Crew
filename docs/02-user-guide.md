# 2. User Guide (for the candidate)

## Prepare your 3 inputs

### 1. Job Posting URL
- Use the direct link to the job description page.
- Company careers pages (Greenhouse, Lever, Workable, company sites) work best.
- LinkedIn / Indeed often block automated access. If the result looks empty, open the job in your browser, copy the description, and paste it into your write-up under a heading "JOB DESCRIPTION".

### 2. GitHub Profile URL
- Example: `https://github.com/your-username`
- Pin your best repositories and give them clear descriptions: the agents read repo names, languages, stars, topics and descriptions.

### 3. Personal Write-up (most important!)
The agents only know what you tell them. Include:
- Work experience: company, title, dates, what you built, results and numbers
- Education and certifications
- Skills and tools you really use
- Achievements, awards, publications
- Career goals and the kind of role you want

> Tip: 300–800 words gives the best results. Never ask the system to invent experience; it is instructed not to, and you should not submit fabricated facts.

## Run it
1. Paste the three inputs.
2. Click **Generate Application Package**.
3. Wait 2–3 minutes. The progress screen ticks off each step as its agent finishes.
4. Review each tab, then copy or download the files.

## What you receive

| File | What it is | How to use it |
|------|-----------|---------------|
| `job_insights.md` | Analysis of the role, skills, ATS keywords | Read first. Know what the employer wants |
| `candidate_profile.md` | Your strengths, skills, projects, gaps | Check it is accurate; fix your write-up if not |
| `tailored_resume.md` | ATS-friendly resume, already fact-checked | Edit, fill `[Add metric]` placeholders, then download as **PDF** or **Word** |
| Fact check | What the reviewer removed or fixed because your data did not support it | Read it. It tells you what to double-check or add to your write-up |
| `cover_letter.md` | 250–350 word letter based on the resume | Add the hiring manager's name, tweak the opening, download as PDF/Word |
| `interview_materials.md` | Technical + behavioural questions, STAR points, questions to ask | Practise out loud |

## Before you send anything (checklist)
- [ ] Every fact in the resume is true (read the Fact check tab too)
- [ ] All `[Add metric]` placeholders are replaced or removed
- [ ] Dates, titles, and contact details are correct
- [ ] Keywords from `job_insights.md` appear naturally
- [ ] Resume fits 1 page (2 for senior roles)
- [ ] You can explain every project and skill listed

## Downloading as PDF / Word
Every document tab (except Skills) has **PDF** and **Word** buttons next to **Markdown**.
- Use **Word** if you want to keep editing and polishing; use **PDF** for the final copy.
- The PDF uses standard fonts, so characters outside Western European alphabets (for example Bengali or Chinese) may show as `?`. Use the Word export for those.
- You can still copy the Markdown into Google Docs or use Pandoc if you prefer your own styling.

## About the fact check
A separate reviewer agent compares the draft resume with your uploaded resume, write-up and profile, then removes or rewrites anything unsupported. The badge shows **Passed** (nothing changed), **Corrected**, or **Not applied** (the model did not return a usable review, so you see the unreviewed draft). It is a safety net, not a guarantee: still read the final resume yourself.

## Interview preparation plan
1. Read `interview_materials.md` once fully.
2. Write your own answers for the "Tell me about yourself" and top 5 technical questions.
3. Rehearse STAR stories (Situation, Task, Action, Result) out loud.
4. Prepare 3 of the suggested questions to ask the interviewer.
5. Research the company yourself too. AI can miss recent news.
